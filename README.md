# Tinkercad Arduino – 

## Overview

This repository contains **10 Arduino-based IoT projects** developed using **Tinkercad Circuits**, where each project integrates **one sensor** with **one actuator**. These projects demonstrate the fundamentals of sensor interfacing, actuator control, Arduino programming, and IoT automation through virtual circuit simulation.

Each project includes:

* Arduino source code (`.ino`)
* Circuit diagram screenshot (`circuit.png`)
* Detailed project documentation (`README.md`)
